# 🛠️ Fix the Broken Website — PinVerse

Welcome to **Fix the Broken Website**, a two-round debugging showdown. Your site is broken. Your job: hunt it down, fix it, ship it.

## ⚡ The Rounds

**Round 1 — The Bug Hunt** 🔎 *Trace the glitch. Expose the bug.*
Spot every bug, say what triggers it and what *should* happen. Fastest + sharpest teams advance.

**Round 2 — The Hotfix** 🚑 *Kill the glitch. Save the site.*
Fix the site for real — working, clean, no regressions. Winners take it on correctness + speed. Both rounds, same day. No second chances. 😈

## 📌 Your Battlefield: PinVerse

A Pinterest-style gallery in pure **HTML + CSS + JS**. No frameworks. No excuses.

Run it: just double-click `index.html` (or `python -m http.server 8080`).

## 📜 Rules

- Vanilla code only — no React, Tailwind, Bootstrap, jQuery.
- Don't break what already works.
- Every teammate must be able to explain every fix.

Debug the web. Crack the challenge. 🐞🔨
